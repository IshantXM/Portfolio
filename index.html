01 / High-Performance Computing / AVX2 / SIMD 2026 · C++20 / Python / CMake

Vectorized Black-Scholes Options Pricing Engine

High-throughput numerical computing engine leveraging 256-bit AVX2/FMA SIMD kernels.

black_scholes_avx2.cpp Click for Source Repo ↗ 
// 256-bit AVX2/FMA instruction: computes 4 double-precision option contracts simultaneously
__m256d v_d1 = _mm256_div_pd(_mm256_add_pd(_mm256_log_pd(v_s_over_k), v_term), v_vol_sqrt_t);
__m256d v_price = _mm256_sub_pd(_mm256_mul_pd(v_s, v_n_d1), _mm256_mul_pd(v_k_disc, v_n_d2));

// Benchmarks & Verification:
Throughput: 63.6M options/sec (~3.9 ns/option) — 3.6x speedup over scalar baseline
Validation: 4,000,000 randomized market contracts | 6.08 × 10⁻¹⁰ Mean Absolute Error
  • AVX2/FMA Hardware Vectorization: Built a high-throughput Black-Scholes options pricing engine using 256-bit AVX2/FMA intrinsics, processing 4 double-precision contracts per instruction and increasing single-core throughput 3.6x from 17.7M to 63.6M options/sec (~3.9 ns/option).
  • Custom Vectorized Mathematical Kernels: Engineered custom transcendental math kernels for exponential, logarithmic, and error-function evaluation using degree-10/16/24 minimax polynomial approximations, fused multiply-add (FMA), branchless range reduction, and IEEE-754 bit-level operations.
  • Rigorous Numerical Validation: Validated pricing across 4,000,000 randomized market contracts, achieving 6.08 × 10⁻¹⁰ MAE and 4.05 × 10⁻⁹ maximum absolute error, reproducing the analytical benchmark price of $10.450584.
