## 🏛️ Key Projects

### 01. Vectorized Black-Scholes Options Pricing Engine
* **Stack:** `C++20`, `256-bit AVX2/FMA`, `SIMD`, `Python`, `CMake`, `Google Test`
* **Performance:** Single-core throughput of **63.6M options/sec (~3.9 ns/option)** — a **3.6x speedup** over scalar baseline.
* **Accuracy:** Validated across **4,000,000 randomized market contracts** with **6.08 × 10⁻¹⁰ MAE**.
* **Repository:** [black-scholes-option-pricing-engin](https://github.com/IshantXM/black-scholes-option-pricing-engin.git)

### 02. PayGraph – Resilient Payment-Network Routing Engine
* **Stack:** `C++20`, `Graph Algorithms (Dijkstra, BFS)`, `Concurrency`, `CMake`, `Google Test`
* **Architecture:** Finds optimal transaction paths with real-time route replanning and atomic multi-hop guarantees preventing funds from locking during intermediate node failures.
* **Benchmark:** Simulated network of **50,000 accounts** and **400,000 connections**, sustaining **~124 tx/sec** backed by 72 integration tests.

### 03. Aegis – AI Agent Evaluation & Reliability Engine
* **Stack:** `FastAPI`, `Python`, `PostgreSQL`, `Next.js`, `Docker`, `WebSockets`
* **Benchmarking:** Benchmarks 5 reliability dimensions (correctness, safety, robustness, efficiency, tool fidelity) and attributes agent failures into 4 diagnostic classes (tool loops, hallucinations, schema errors, goal drift).
* **Load Telemetry:** Sustained **120 req/s at 495ms p99 latency** with 0% error rate across 1,600+ execution traces.

### 04. AI-Powered WhatsApp Notification Router
* **Stack:** `Whisper`, `Vision OCR`, `GPT-5-mini`, `Gemini Text Embeddings`, `BM25`, `Python`
* **Pipeline:** Multimodal prioritization combining audio transcription, screenshot OCR, and hybrid lexical/dense retrieval.
* **Metrics:** **0.62 weighted F1-score** across 110-message test set with **0% false-positive scam detection** (~$0.11 / 1k msgs, 1.75s latency).
